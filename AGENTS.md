# AGENTS.md

Context for any AI agent working in this repo.

## What this repo is

A **research, brainstorming and ideation workspace** for a one-person digital agency that builds and manages websites for small local businesses (barbers, hairdressers, salons, similar). We use it to think about and plan future features and services that touch a client's **broader business processes**, not just their website.

It is deliberately **client-agnostic and project-agnostic**. It is not a code repo, and it is not tied to any single client.

## Read first

1. `docs/context/agency-profile.md`: who we are, constraints, typical clients
2. `docs/context/business-process-map.md`: the lens for finding opportunities
3. `docs/context/evaluation-framework.md`: how we judge ideas
4. `docs/context/pricing-and-service-models.md`: third-party costs, what we charge, managed vs client-owned

## Layout

```
docs/context/   Stable background context (read before substantial work)
ideas/          One file per idea, any stage
research/       Findings on tools, vendors, tech, markets, regulation (+ small experiments)
processes/      Deep dives on a business process for a business archetype
templates/      Copy these to start a new idea / research note / process deep dive
.cursor/rules/  Always-on and contextual rules for the AI
```

## Working agreements

- Think and document first; build only throwaway experiments.
- Start from the business problem, not a technology.
- No real client details in any file. Use archetypes.
- Be realistic about a solo operator's capacity and small-business owners' time.
- Every idea with third-party costs needs a cost and pricing view, for both the managed and client-owned models.
- Verify external facts (pricing, features, policies) with current sources and date them.
- Illustrative examples from conversation (e.g. a chatbot) are **not** plans or decisions.
- Follow the conventions in `.cursor/rules/doc-conventions.mdc` (naming, frontmatter, status).

## Status

The repo is newly set up. `ideas/`, `research/` and `processes/` are empty on purpose.
